preview on 2026-07-30 using OpenAI's built-in image generation tool.

They use original fictional scenes and do not use third-party source images.
The generation constraints excluded celebrity likenesses, recognizable actors,
copyrighted characters, existing movie-poster compositions, logos, titles,
lettering, captions, watermarks, and signatures.

All files are cropped to `1060 × 616`, four times their `265 × 154` display size
in the Figma frame.
