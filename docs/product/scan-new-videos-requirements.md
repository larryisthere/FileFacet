# 扫描新视频 Requirements

- 状态：HTML 原型与正式实现已通过用户验收（2026-08-30）
- 原型：[`../prototypes/scan-new-videos/index.html`](../prototypes/scan-new-videos/index.html)
- 设计：[`scan-new-videos-design.md`](scan-new-videos-design.md)
- 验收：[`scan-new-videos-acceptance.md`](scan-new-videos-acceptance.md)

## 1. 目标

用户可以主动扫描已经纳入 FileFacet 的文件夹，查看其中尚未导入的视频，并选择部分或全部候选视频导入。扫描不会自动执行，候选结果不会在用户确认导入前写入资料库。

## 2. 用户故事

1. 作为用户，我希望检查已有素材文件夹中后来新增的视频，从而无需逐个回忆和重新选择每个来源。
2. 作为用户，我希望先查看扫描结果，再决定导入哪些视频，从而保持对资料库内容的控制。
3. 作为用户，我希望扫描结果可以暂时保留并随时关闭，从而可以在资料库与候选视频之间切换。
4. 作为用户，我希望此前单独导入视频的文件夹也能加入扫描范围，从而覆盖分散的素材位置。

## 3. 功能要求

### 3.1 扫描入口

- 工具栏在搜索框左侧显示“扫描新视频”按钮。
- “文件”菜单在“导入视频与文件夹…”之后显示“扫描新视频”。初版不设置快捷键。
- 两个入口调用同一个扫描命令并共享启用状态。
- 当资料库没有已导入视频、手动导入正在进行、扫描正在进行或设置页面正在显示时，扫描命令不可用。
- 当用户发起扫描时，系统应结束当前删除撤回生命周期，并使用中部就地状态显示扫描进度。

### 3.2 扫描范围与文件访问

- 系统应扫描用户此前选择导入的文件夹，以及用户通过扫描恢复流程明确加入的文件夹。
- 通过单个视频文件获得的访问范围只覆盖该文件；系统不得据此枚举其父文件夹。
- 当存在尚未覆盖的单文件来源父目录时，扫描结果应说明仍有多少文件夹未检查，并提供“选择文件夹…”操作。
- 用户通过“选择文件夹…”加入的目录应保存为后续扫描范围，即使本次没有发现或导入视频也应保留。
- 当本次选择的文件夹全部无法加入时，系统应保留此前候选结果并显示失败说明；迟到的文件夹准备任务不得覆盖新的扫描或手动导入状态。
- 外置卷离线、访问失效或单个目录读取失败时，系统应继续扫描其他可访问目录，并以数量说明未完成范围。
- 扫描沿用现有导入发现规则：递归检查普通目录，跳过隐藏内容、Finder Alias、符号链接、Package 和不支持的视频类型。

### 3.3 候选识别

- 扫描应按稳定文件身份优先、标准化文件位置回退的现有规则，与整个 FileFacet 资料库进行判重。
- 已导入视频不得出现在候选结果中；同一新视频被重叠扫描范围发现时只显示一次。
- 候选结果只保存在当前 App 会话，不写入视频、标签、媒体信息、持久缩略图或导入记录。
- 候选卡片使用 macOS Quick Look 在后台生成会话级预览，并显示文件名、相对位置、格式、大小与日期；预览失败时显示通用影片图标。完整媒体解析和持久缩略图仍在视频导入后使用现有管线完成。

### 3.4 临时分类与生命周期

- 当扫描发现候选视频时，左侧最上方显示临时“扫描结果”分组，其中包含“待导入视频”预置分类及当前数量，并自动进入该分类。
- 用户切换到资料库分类、标签或智能分类后，临时分组继续保留；再次选择“待导入视频”应返回当前候选结果。
- 临时分组提供关闭操作。仍有候选时，关闭后清空本次候选结果和选择，已完成的导入继续保留。
- 扫描没有发现候选视频时，中部状态显示“未发现新视频”，左侧不创建空的临时分组。
- 用户再次发起扫描时，系统应替换上一轮候选结果并清空上一轮选择。
- 用户从菜单、选择器或 Finder 拖入发起新的手动导入时，系统应结束当前扫描结果生命周期。

### 3.5 选择与导入

- 候选网格支持单选、Command 多选、点击选择和“选择全部 / 取消全选”。
- 操作栏应显示已选数量，并根据选择显示“导入所选视频”或“导入 N 个视频”。未选择候选时导入操作不可用。
- 搜索框在扫描结果中按文件名和相对位置过滤可见候选；搜索不改变已选候选。
- 用户可以导入部分候选。导入完成后，本批成功处理的候选从扫描结果移除，其余候选继续保留。
- 当本次扫描的全部候选均成功处理、没有未检查文件夹且没有失败项时，系统应自动关闭临时分类。若本次扫描会话全部为新增视频，进入“最近添加”，选中本次扫描会话中全部成功新增的视频并滚动到第一项；若处理结果包含已存在记录，进入“所有视频”，选中本次扫描会话中全部成功处理的视频并滚动到第一项。
- 候选已经归零但仍有文件夹未检查或检查失败时，临时结果继续保留，并说明已处理全部发现的视频但扫描范围尚未完整检查。
- 自动完成跳转不再显示扫描完成空状态、“完成”通知或重复的“查看”操作。
- 扫描候选导入应复用现有全局判重、Finder 标签首次导入、数据库写入、媒体解析、缩略图、刷新和结果反馈。
- 候选来自文件夹时，导入应遵循当前文件夹导入偏好；偏好为“每次询问”时，在写入前显示现有导入方式选择。
- 单个候选处理失败时应保留在结果中，其他候选继续导入；结果反馈区分新增、已存在和失败数量。

### 3.6 性能、隐私与只读边界

- 目录枚举、候选判重和导入写入应在后台执行；界面更新回到 MainActor。
- 扫描期间用户仍可浏览现有资料库；同一时间只运行一个扫描或手动导入任务。
- 扫描不移动、重命名、修改或删除原视频。
- 日志只记录目录数、候选数、失败数和错误类别，不记录完整路径、文件名、标签内容或 Bookmark 数据。
- FSEvents 继续只维护已导入视频的状态，不自动创建候选结果或导入新视频。

## 4. 明确排除

- 自动定时扫描、启动扫描和 FSEvents 自动导入。
- 持久保存每轮候选结果或跨启动恢复选择。
- 持久保存候选预览或在扫描阶段解析完整媒体信息。
- 用户可见的完整来源文件夹管理页面。
- 内容哈希副本去重。

## 5. EARS 验收标准

1. 当资料库存在已导入视频且没有导入或扫描任务时，系统应同时启用工具栏和“文件”菜单中的“扫描新视频”。
2. 当用户通过任一入口发起扫描时，系统应递归检查当前可访问的扫描文件夹，并显示扫描进度。
3. 当扫描发现尚未导入的视频时，系统应显示临时“扫描结果 / 待导入视频”导航、唯一候选网格和候选数量。
4. 当扫描再次发现已导入视频或重叠目录中的同一视频时，系统不得把它加入候选结果。
5. 当用户关闭临时扫描分组时，系统应清空候选和选择，同时保留此前完成的导入。
6. 当用户切换到其他分类后再次选择“待导入视频”时，系统应恢复当前候选和选择。
7. 当用户选择部分候选并导入时，系统应只处理所选候选，移除成功项并保留其余候选。
8. 当全部候选均成功处理、没有未检查文件夹且没有失败项时，系统应自动关闭临时分组；全部为新增视频时进入“最近添加”并选中本次扫描会话的全部新增视频，包含已存在记录时进入“所有视频”并选中全部成功处理的视频。
9. 当扫描范围包含此前单独导入的视频时，系统应说明未检查的文件夹数量，并允许用户选择目录加入后续扫描范围。
10. 当部分目录离线、失去访问或读取失败时，系统应继续处理其他目录，并显示未完成范围数量。
11. 当扫描没有发现候选视频时，系统应显示“未发现新视频”，且不显示空的临时扫描分组。
12. 当用户发起新的手动导入或再次扫描时，系统应结束或替换上一轮候选生命周期，不把旧选择应用到新结果。
13. 当候选导入完成时，系统应继续遵循全局判重、文件夹标签偏好、Finder 标签首次导入和原视频只读规则。
