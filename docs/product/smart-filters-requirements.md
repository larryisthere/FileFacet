# 组合筛选、排序与智能分类需求

- 状态：已实现并经用户验收
- 日期：2026-07-31
- 交互原型：[`../prototypes/smart-filters/index.html`](../prototypes/smart-filters/index.html)

## 用户目标

用户可以在当前资料库或标签范围内组合文件名、标签、媒体属性和时间条件，直接看到条件关系与结果变化；常用组合可以保存为智能分类，后续从侧栏一键重新使用。

## 搜索、范围与筛选的关系

1. 工具栏搜索只匹配文件名，属于当前会话中的临时搜索。
2. 资料库系统分类和标签分类属于基础范围；进入标签后添加搜索、筛选或排序，结果继续限定在该标签及其后代中。
3. 标题下方的规则状态行只显示已生效的范围、临时搜索、筛选条件和排序；无筛选条件时显示“添加筛选”文字入口，出现任一筛选条件后收紧为带 Tooltip 和辅助功能标签的图标。默认排序独立显示“添加排序”文字入口，应用排序后显示排序 Chip。
4. 添加或编辑具体条件时，在对应入口或条件下方显示临时 Popover；Popover 内维护草稿，点击“完成”后一次应用并刷新结果，“取消”、`Esc` 或点击外部区域放弃草稿。
5. 普通系统分类和标签之间切换时，保留当前临时搜索、筛选和排序。
6. 进入智能分类时载入已保存规则，并清空工具栏临时搜索，避免临时条件混入持久规则。
7. `⌘F` 聚焦并选中文件名搜索框内容；`⇧⌘F` 打开“添加筛选条件”菜单。两项能力同时出现在“编辑”菜单中。

## 条件与关系

支持以下持久筛选条件：

- 文件名包含；多个文件名条件同时存在时全部满足。
- 标签包含全部、包含任一或排除；标签匹配沿用父标签包含全部后代的现有语义。
- 未打标签。
- 最近加入 7、30 或 90 天。
- 最近创建 7、30 或 90 天。
- 时长至少 1、2 或 5 分钟。
- 文件大小至少 500 MB、1 GB 或 2 GB。
- 分辨率宽度至少 1080p 或 4K。

条件组可以选择“匹配全部条件”或“匹配任一条件”。基础范围、临时文件名搜索、持久文件名条件和由基础标签转换的必选标签始终与条件组取交集，避免切换关系时扩大到基础范围之外。

新建标签条件不默认选择标签，也不继承已有条件；至少选择一个标签后才能完成。编辑时允许先清空再重新选择，完全相同的条件不能重复添加，部分重叠条件继续保留以支持组合关系。没有标签时不允许新增标签条件。智能分类引用的标签被删除后，规则显示“已删除标签”，结果为空，用户可以移除或替换该条件。

## 排序

支持按文件名、加入日期、创建日期、修改日期、时长、文件大小和分辨率排序。文件名使用 A 到 Z / Z 到 A；日期使用最新 / 最早优先；数值使用从小到大 / 从大到小。未设置时沿用文件名升序。

## 智能分类

1. 当前查询可以保存为命名智能分类，显示在侧栏独立分组中，并显示实时结果数量。
2. 保存时将当前标签范围转换为必选标签，将“未打标签”转换为对应条件，将“最近添加”转换为最近加入 30 天。
3. “离线”属于运行时访问状态，不能保存为智能分类；处于该分类时禁用保存入口并说明原因。
4. 智能分类名称在同一资料库内忽略大小写和变音符号后保持唯一。
5. 双击智能分类，或从右键菜单、可见的 `•••` 菜单选择“重命名”，都在侧栏当前行进入编辑；`Return` 或失焦校验并保存，`Esc` 取消并恢复原名称，空名称或重名时保留编辑状态。
6. 每次完成条件编辑后预览智能分类结果，并显示“规则已修改”“还原”“另存为”和“更新”。
7. 存在未保存修改时切换分类，提示“更新并继续”“放弃更改”或“取消”；更新失败时留在原智能分类并保留草稿。
8. 删除当前智能分类后回到“全部视频”。删除智能分类不改变视频、文件或标签。

普通分类右侧的“清除”使用图标按钮，保存入口使用“保存”文字按钮；悬停提示和辅助功能标签说明完整的“存为智能分类…”动作。智能分类脏状态中的还原、另存为和更新保留文字，确保用户可以区分不同提交结果。

## 数据与边界

- 智能分类只保存查询规则、名称、顺序和时间，不保存结果快照。
- 视频导入、移出、标签关系变化、标签树变化或媒体信息更新后，当前结果和智能分类数量按最新事实重新计算。
- 用户数据中的文件名、标签名和智能分类名称保持原值，不参与翻译。
- 所有查询只读取资料库索引，不修改、移动、重命名或删除原视频。
- 英文和简体中文界面均覆盖规则状态行、Popover、提示和侧栏操作。

## 验收标准

1. 用户在全部视频、系统分类和标签下添加文件名搜索、筛选和排序时，状态行、结果和基础范围关系正确。
2. 添加和编辑条件通过临时 Popover 的草稿完成；取消不会改变结果，完成只触发一次查询，全部 / 任一关系可见且结果符合规则。
3. 当前查询保存后可从侧栏恢复；标签、未打标签和最近添加范围均完整保留，离线范围无法保存。
4. 智能分类的实时预览、还原、另存为、更新、离开确认、重命名和删除路径完整。
5. 标签被删除、资料库为空、没有标签、空标签草稿、完全重复条件、多条件和多文件名条件等边界不会产生无效或静默扩大的结果；条件 Chip 的叉号可以移除对应条件。
6. 英文和简体中文文案完整，动态用户数据保持原值。
7. `⌘F` 与 `⇧⌘F` 可以分别进入文件名搜索和添加筛选，菜单、Tooltip 与辅助功能标签能够说明对应动作。
8. 构建成功只证明代码和资源可编译；查询结果、交互和视觉由用户验收。
