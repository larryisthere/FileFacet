# 文件夹结构生成层级标签 Requirements

状态：已实现并通过用户验收（2026-07-30）

关联基础能力：`docs/product/manual-video-import-requirements.md`

交互原型：`docs/prototypes/folder-structure-tags/index.html`

## 1. 目标

用户导入已经按文件夹整理的视频时，可以直接把目录结构转换为 FileFacet 层级标签，同时保留现有应用标签、Finder 标签和原视频位置。

## 2. 导入方式

文件夹导入支持三种偏好：

- 每次询问。
- 直接导入视频。
- 导入视频并创建目录标签。

菜单、`⇧⌘I` 和 Finder 拖入共用同一偏好。仅包含视频文件的输入始终直接导入。

“每次询问”在正式导入前显示原生 Sheet。用户可以选择“以后导入文件夹时始终使用此方式，不再询问”；取消 Sheet 后不保存选择，也不启动导入。

设置中的“导入”分类允许用户修改默认方式或恢复“每次询问”。

## 3. 目录标签规则

- 默认从所选文件夹内部第一层目录开始创建标签，所选文件夹自身不进入标签树。
- 用户可以启用“将所选文件夹本身创建为根标签”。
- 启用根标签后，所选文件夹直属视频关联根标签；多个有效根目录分别创建根标签。
- 每个视频只关联其目录路径中最深层的标签；现有父标签递归筛选和计数覆盖全部后代。
- 同父级下使用现有名称规范化口径复用标签；不同父级下允许同名标签。
- 已有视频追加缺少的目录标签，现有应用标签和 Finder 标签关系全部保留。
- 新视频继续执行一次 Finder 标签导入；已有视频不重新同步 Finder 标签。
- 重复导入不重复创建视频、标签或视频标签关系。
- 目录标签是普通 FileFacet 标签，导入后可以重命名、移动、合并或删除；后续文件夹改名不自动同步标签。

## 4. 输入与边界

- 只要输入计划包含文件夹，整批最多询问一次。
- 混合输入中的独立视频不生成目录标签。
- 父目录、子目录和内部文件同时输入时，沿用现有父目录覆盖折叠规则。
- 多个独立根目录分别计算标签路径；未包含根目录时，相同内部标签路径在全局标签树中复用。
- Finder 目录别名、符号链接和 macOS Package 不进入导入计划，也不枚举其后代。
- 空文件夹、无法读取的输入、部分失败和取消继续使用现有导入反馈与分批提交规则。
- 深层目录使用迭代方式逐层处理，不设置产品层级上限。
- 空白目录名称不生成标签，视频继续导入。
- 未知或缺失的偏好值回退“每次询问”。
- 原视频保持只读，不移动、重命名、修改或删除。

## 5. 验收标准

1. 仅选择或拖入视频文件时，不显示方式 Sheet，也不创建目录标签。
2. 包含文件夹且偏好为“每次询问”时，菜单、快捷键和拖入显示同一方式 Sheet。
3. 固定为直接导入或目录标签导入后，不再显示方式 Sheet；菜单仍显示系统文件选择器。
4. 默认排除所选根目录，并在 Sheet 中清楚说明标签从内部第一层开始。
5. 启用根标签后，所选文件夹进入标签树，直属视频关联根标签。
6. 已有视频重新导入时保留原标签并追加缺少的最深层目录标签。
7. 同父级规范化同名标签复用，不同父级同名标签分别存在。
8. Finder 目录别名、符号链接和 Package 被跳过，其余输入继续导入。
9. 重复导入不会增加重复视频、标签或关系。
10. 设置和 Sheet 中“不再询问”保存的方式与根标签选项在重启后保持一致。
