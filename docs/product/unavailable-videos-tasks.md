## 任务

- [x] 1. 明确统一分类和状态边界
  - 固化四个预置分类及 `Command-1` 至 `Command-4` 映射。
  - 用户界面只显示正常、离线和无法访问；内部区分访问连接丢失、离开已知位置和用户主动移出。

- [x] 2. 更新 HTML 原型
  - 展示离线与无法访问视频共存的“不可用视频”。
  - 覆盖 Command 按住提示、松开恢复和快捷切换。
  - 覆盖重新接入、重新定位和永久移除。

- [x] 3. 用户验收 HTML 原型
  - 确认分类名称、固定顺序、徽标、操作和快捷键提示。

- [x] 3.1 验收 Inspector 处理模式 HTML 原型
  - 不可用分类使用“处理｜详情”，默认打开处理页，并覆盖无法访问、离线和多选。
  - 右键菜单同步提供适用于当前状态的重新定位和移除操作。

- [x] 3.2 验收重新定位反馈 HTML 原型
  - 覆盖重新定位进行中、成功、文件已存在和其他失败。
  - 确认中部通知、“查看已有视频”、重试、主动关闭和切换浏览上下文后的生命周期。

- [x] 3.3 验收严格内容确认 HTML 原型
  - 覆盖完整内容确认、证据不足或内容不同、重新选择、取消和用户明确继续。
  - 确认差异信息、默认操作和继续连接后的数据保留范围。

- [x] 4. 实现持久不可用状态
  - 调整静默维护、数据库状态转换、废纸篓识别、最后已知位置和自动恢复。
  - 保持离线、权限失败和 Bookmark 失效的安全边界。

- [x] 5. 实现不可用查询与处理操作
  - 合并持久不可用、运行时访问连接丢失和运行时离线结果并去重，对用户统一显示“无法访问”或“离线”。
  - 实现重新定位、单选或批量移出及撤回。

- [x] 5.1 实现重新定位内容确认
  - 保存本地完整内容指纹，并在数据库更新前完成文件有效性、内容一致性和已有记录冲突检查。
  - 证据不足或内容不同交由用户确认；用户未确认时保持原记录不变。

- [x] 6. 实现四个预置分类快捷键
  - 注册主菜单快捷键并复用现有导航入口。
  - 实现 Command 按下提示、失焦复位和可访问性帮助。

  - 无签名 Debug 构建已完成；默认签名构建受本机开发证书限制。
