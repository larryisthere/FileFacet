# 一键恢复交互稿（待用户确认）

2026-09-14。沿用共享外壳、macOS 系统字体与现有色彩，虚构数据模拟三阶段流程。未修改正式 App。

- 恢复前：10 个访问失效或状态不确定的视频可尝试恢复，2 个已确认原位置缺失、2 个设备离线的视频不参与。无符合条件的视频时隐藏一键恢复按钮。
- 恢复中：点击即开始，按原目录逐个请求系统确认，不增加应用内目录总览、多选页或扩大到祖先目录。确认后核对本目录，再请求下一目录。可停止，系统窗口取消会结束本次恢复，保留已完成结果。窗口为概念模拟；本机单目录预定位、精确目录确认和重启授权恢复已由用户验收，多目录场景尚待验证，不承诺一次确认能授权多个目录。
- 恢复后：默认 8 个成功、1 个内容不同、1 个原位置缺失；不可用列表剩 6 个（含原来排除的 4 个）。成功项移出，剩余项按原因提供重新定位或等待设备接入。全部成功指参与本次恢复的 10 个；原本排除的 4 个继续保留。全部失败可重试。

左侧可切换部分成功、参与项全部成功、全部失败、无适用项。模拟重启通过 sessionStorage 保留已完成结果和模拟授权，不代表真实授权持久化验证。新视频候选不参与恢复，也不会被导入。

首个验收案例：默认场景点击一键恢复，依次确认旅行、工作、生活三个原目录。完成显示已恢复 8 个、2 个未恢复，不可用列表剩 6 个。无应用内手选目录步骤。

本轮仅执行文本级语法、链接、ID 及 diff 检查，未运行浏览器预览、截图或交互测试。正式实现仍需内容指纹核对、持久关联和静默维护协调。


## 本次交互稿校正

- 重新定位的内容一致/不同等模拟选项移到共享左栏；在打开文件窗口前选择下次结果。
- 文件窗口仅显示示例位置与可选文件名，不提前显示内容判断；选择后先核对，再显示结果。
- 内容一致成功返回；内容不同/缺少比较依据默认重新选择，仍然连接保留显式确认；读取失败可重选；重复记录可跳转选中既有条目，不修改当前失联记录。
- 核对取消会清除迟到回调；结果通知可关闭；全部成功使用成功文案，部分失败不染为全成功状态。
- 新版首次加载使用新的会话存储键，避免旧演示结果混入；模拟重启仍保留本版已完成状态。
- 文件选择器仍为 HTML 概念模拟，不读取本机文件；完整系统窗口样式以原生实验及正式 App 为准。

静态检查范围：JavaScript 语法、ID 引用、重复 ID、资源链接、diff 空白检查。没有运行浏览器或实际点击，用户已确认重新定位主路径通过；新增正式代码的正确性补强仍待验收。
